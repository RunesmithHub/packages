# Runesmith Hub packages

Published Runesmith plugin packages, their source archives and their images, one release per plugin version.

Releases here are created only by the hub's publishing workflow. Install plugins from Runesmith's plugin manager or the hub website, which
check every file against the hub's signed index; downloading files from this repository by hand skips those checks.

To report a problem with a plugin, see [the hub's security policy](https://github.com/RunesmithHub/.github/blob/main/SECURITY.md).
